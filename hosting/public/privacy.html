プライバシーポリシー

制定日: 2026 年 9 月 23 日

「カレンダー連携」（以下「本アプリ」）は、利用者が連携した Google アカウントのカレンダーの予定を、 他の連携アカウントのカレンダーに反映するためのアプリです。本アプリが取得する情報と、その扱いを以下に定めます。

1. 取得する情報

  • Google アカウントのメールアドレスと、アカウントを識別する ID
  • Google アカウントが Google Workspace か個人アカウントか（Workspace のドメイン名）
  • 連携したアカウントのカレンダーの一覧（名前、タイムゾーンなど）
  • 連携したアカウントのカレンダーの予定（時刻、タイトル、説明、参加者の人数と自分の返答状況、会議リンクの有無など）
  • Google から発行される認証情報（リフレッシュトークン）

2. 利用目的

取得した情報は、次の目的にだけ利用します。

  • 利用者本人であることの確認と、アプリへのログイン
  • 利用者が設定した同期設定に従い、元の予定を評価して、同期先のカレンダーに予定を作成・更新・削除すること
  • 連携したアカウントの予定を、アプリ内の統合カレンダーに表示すること

予定の内容は、同期するかどうかの判定と画面表示のためにその都度読み取るもので、本アプリのデータベースには保存しません。 同期先に作成する予定には、利用者が同期設定で選んだ内容（タイトル、説明、場所など）だけを書き込みます。

3. 保存する情報と保管方法

  • 保存するのは、連携アカウントのメールアドレスと ID、カレンダーの一覧、同期設定、元の予定と同期先の予定の対応表（予定の ID と更新判定用の値）、同期の状態です
  • リフレッシュトークンは暗号化（AES-256-GCM）してから保存します
  • 保存先は Google Cloud の Firestore（東京リージョン）で、利用者の端末やブラウザから直接読み書きすることはできません

4. 第三者への提供

取得した情報を第三者に販売・提供することはありません。広告や、同期以外の目的での分析にも利用しません。 ただし、法令に基づく場合を除きます。

5. Google API から取得した情報の扱い

本アプリによる Google API から取得した情報の利用と他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）に従います。

6. 連携の解除とデータの削除

  • アプリの「アカウント」画面で連携を解除すると、そのアカウントの認証情報と連携情報を削除し、Google 側の許可も取り消します。そのアカウントに関わる同期設定は無効になり、本アプリが作成した予定も削除します
  • 同期設定を削除すると、その設定で作成した予定を削除します
  • Google アカウントのサードパーティ製のアプリとサービスから、本アプリのアクセスをいつでも取り消せます

7. お問い合わせ

本ポリシーに関するお問い合わせは、Google の同意画面に表示されるサポートメールアドレスまでご連絡ください。

8. 改定

本ポリシーを改定する場合は、このページで公開します。
